Why the 46 blocked cases are held

A case can be held for more than one reason, so these do not sum to 46. Every one of the 18 batch cases is also a part-payment case — the batch posting is the part payment.

Export is not wired in this view. The built report needs a working CSV of the row-level detail, excluding every name field. An Artifact page cannot start a download for a viewer, so it is specified rather than demonstrated here.
A refund never clears a case. The verdict records that the control failed; recovery is computed fresh each run and shown separately. A case that is later refunded moves from Never refunded to Partly refunded — it stays confirmed.
Fines are excluded. Where a duplicate payment carries overstay days, only that era's government fee is counted here; the fine belongs to the overstay audit.
No approved KPI exists for this definition. Every figure is an unverified ad hoc measure pending Data Catalog registration. No personal data is shown or exported.
