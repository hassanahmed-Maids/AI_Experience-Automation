## One reporting defect found

`population_cancelled_in_scope` reported **22,630**, which is wrong — it should be the count of
cancelled contracts terminated in or after the cutoff (a few hundred), not nearly the whole
cancelled cohort.

Cause: on a **targeted** run the scope filters are deliberately bypassed so a named contract is
always scored, and `cancelledInScope` is counted before the targeted selection. So the number is
only wrong on targeted runs; on a full run it is correct. **Not a scoring defect** — the two cases
are right — but a misleading number in a run report, which should be fixed before anyone reads one
of these for real.
